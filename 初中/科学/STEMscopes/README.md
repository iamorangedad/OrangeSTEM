# STEMscopes Science 初中科学 6–8

本目录的材料改编自 Accelerate Learning 出版的 **STEMscopes Science NGSS 3D** 初中课程，采用官方的**综合版（Integrated）**年级安排：六、七、八年级各 4 个单元（Bundle），每个单元若干章（Scope），每个 Scope 按 5E 流程展开。年级、单元和 Scope 取自官方《Review and Digital Navigation Guide – Middle School (Integrated)》（2024 年 1 月），NGSS 对齐取自官方《Program Guide》（2024 年 10 月），活动细节取自官方 2024 版六、七、八年级样课。小学部分见 [STEMscopes K–5](../../../小学/科学/STEMscopes)。

> **AI 辅助声明**：本目录的大纲和海报由 AI 辅助整理和绘制，中文是本项目的译写，没有照搬原书文字。原书内容需要登录才能查看，海报只依据公开的单元名、Scope 名、NGSS 表现期望和官方样课；没有公开依据的探究标「示例探究」，只有简介的官方活动标「步骤为示意」，自己举的数字标「示例」。**公开发布或用于教学前需要人工审核。**

## 海报

综合版共 12 个单元、60 个不同的 Scope（「动能」和「人类对环境的影响」在六、八年级重复出现，只在六年级出海报），每个 Scope 一张海报。已完成 0 张（PNG + PDF，按年级放在 `海报/六年级/` 等子目录）：六年级 0、七年级 0、八年级 0；其中教材活动 0 张、示例探究 0 张。每张海报 3 行对应 5E 的 Engage（现象）、Explore（探究）、Explain（结论），小结框里的「拓展」对应 Elaborate，有安全提示，底部标注教材来源。只用公制单位和人民币。
