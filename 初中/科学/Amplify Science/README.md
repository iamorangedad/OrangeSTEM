# Amplify Science 初中科学 6–8

本目录的材料改编自 Amplify Science 初中科学课程（6–8 年级）：由加州大学伯克利分校劳伦斯科学馆（Lawrence Hall of Science）与 Amplify 合作研发，面向 NGSS。按全国版“综合模式”编排，每个年级 9 个单元：1 个启动单元、6 个核心单元、2 个工程实习单元。单元下分章（Chapter），章下分课（Lesson），每个单元围绕一个学生角色和锚定现象展开。

> **AI 辅助声明**：本目录的大纲和海报由 AI 辅助整理和绘制，中文为本项目的意译，没有照搬原书文字。原书内容需登录才能查看，海报只依据公开的单元、章节和课题标题；海报中没有公开依据的操作步骤标「步骤为示意」，自己举的数字标「示例」。**公开发布或用于教学前需要人工审核。**

## 海报

全套 27 个单元。启动单元和核心单元共 80 章，每章一张海报；6 个工程实习单元不分章，每个单元一张海报。共 86 张，已完成 0 张（PNG + PDF）：六年级 0、七年级 0、八年级 0。每张海报用 01/02/03 三步画出这一章的锚定问题和关键课（标注课号），底部标注教材来源。海报只用公制单位和人民币，需要注意安全的地方写在小结框里。
