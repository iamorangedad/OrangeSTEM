# FOSS 初中科学 6–8

本目录的材料改编自 FOSS（Full Option Science System）初中科学课程：加州大学伯克利分校劳伦斯科学馆（Lawrence Hall of Science）研发，School Specialty / Delta Education 出版发行。采用的版本是 **FOSS Next Generation 初中版（©2018–19，NGSS 版）**，共 11 门课程（Course），课程下分探究（Investigation），探究下分部分（Part）。

**按课程分组**：FOSS 初中按课程而不是按年级编排，每门课程可以安排在 6–8 年级的任何一年。下面按 FOSS 官方推荐的综合年级顺序排列课程，「推荐年级」只是参考，学校可以自己调整。

> **AI 辅助声明**：本目录的大纲和海报由 AI 辅助整理和绘制，中文是本项目的意译，没有照搬原书文字。原书内容需要登录才能查看，海报只依据公开的课程、探究和部分标题以及官方的课程介绍；海报中没有公开依据的操作步骤标「步骤为示意」，自己举的数字标「示例」。**公开发布或用于教学前需要人工审核。**

## 海报

全套 11 门课程、74 个探究，每个探究一张海报（部分标题有三成左右查不到，所以没有按部分出海报，原因见大纲）。已完成 0 张（PNG + PDF）：推荐六年级的课程 0 张、推荐七年级的课程 0 张、推荐八年级的课程 0 张。每张海报用 01/02/03 三步画出这个探究的关键内容（能查到标题的部分会标出部分号），底部标注教材来源。海报只用公制单位和人民币，需要注意安全的地方写在小结框里。
