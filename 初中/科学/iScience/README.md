# Glencoe Integrated iScience 初中科学（课程一至三）

本目录的材料改编自麦格劳-希尔（McGraw Hill，Glencoe 品牌）出版的 **Glencoe Integrated iScience** 初中综合科学教材，共三册：Course 1（六年级）、Course 2（七年级）、Course 3（八年级），现行版 ©2017（第一版 ©2012）。单元和章取自麦格劳-希尔 2024 年和 2022 年科学教材目录里的官方目录，并用 2012 版学生用书的书目记录核对。

> **版本说明**：iScience 是一套**较早的教材**。麦格劳-希尔现行的初中 NGSS 教材是 **Inspire Science 6–8**（©2020），但 iScience 仍在目录里销售。本目录按用户指定的 iScience 来做。小学部分见 [Inspire Science K–5](../../../小学/科学/Inspire%20Science)。

> **AI 辅助声明**：本目录的大纲和海报由 AI 辅助整理和绘制，中文是本项目的译写，没有照搬原书文字。原书内容需要登录才能查看，海报只依据公开的单元名和章名；官方实验没有公开，所以所有探究都标「示例探究」，自己举的数字标「示例」，名称有出入的章在大纲里标「待核」。**公开发布或用于教学前需要人工审核。**
