# CPM Core Connections Course 1–3

本目录整理 **CPM Core Connections, Courses 1–3**（CPM Educational Program 出版，对应六到八年级）的章节结构，并为每章做一张中文知识海报。CPM 是美国加州的非营利教材机构，课堂以小组合作解题为主；教材**没有开放许可**（© CPM Educational Program，版权所有）。
章名取自 CPM 官网中学页面的目录，课名取自官网公开的《Text to CCSS Standards》对照表，链接见大纲。

> **AI 辅助声明**：本目录的大纲和海报由 AI 辅助整理和绘制，中文是本项目的译写，没有照搬原文，也没有使用原教材的题目和插图。海报里的数字和情境标「示例」，属于自编示意；拿不准的地方标「待核」。**公开发布或用于教学前需要人工审核。**
