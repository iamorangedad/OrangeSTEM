# Carnegie Learning Middle School Math Solution 6–8（Texas Math Solution）

本目录整理 Carnegie Learning **Middle School Math Solution** 六到八年级的结构，依据的是官网公开的**德州版（Texas Math Solution，© 2021）**学生用书目录，并为每个模块做一张中文知识海报。教材**没有开放许可**（© Carnegie Learning, Inc.，版权所有）。每个年级 5 个模块，每个模块含 2–4 个 Topic。为什么选德州版、和通用版的区别，见大纲开头。

> **AI 辅助声明**：本目录的大纲和海报由 AI 辅助整理和绘制，中文是本项目的译写，没有照搬原文，也没有使用原教材的题目和插图。海报里的数字和情境标「示例」，属于自编示意；拿不准的地方标「待核」。**公开发布或用于教学前需要人工审核。**
