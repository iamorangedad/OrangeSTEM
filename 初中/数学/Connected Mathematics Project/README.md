# Connected Mathematics Project（CMP3）6–8

本目录整理 **Connected Mathematics Project 第 3 版（CMP3）** 六到八年级的单元结构，并为每个单元做一张中文知识海报。CMP 由密歇根州立大学 CMP 项目组编写（最初由美国国家科学基金会资助），Pearson 出版、现由 Savvas Learning 发行，**没有开放许可**（© Michigan State University，版权所有）。
单元名和各 Investigation 的标题、Problem 数、建议课时取自 MSU 官网公开的三份《Authors' Scope and Sequence》，链接见大纲。CMP 以问题驱动：每个单元由 3–5 个 Investigation 组成，每个 Investigation 有 2–5 个 Problem。

> **AI 辅助声明**：本目录的大纲和海报由 AI 辅助整理和绘制，中文是本项目的译写，没有照搬原文，也没有使用原教材的题目和插图。海报里的数字和情境标「示例」，属于自编示意；拿不准的地方标「待核」。**公开发布或用于教学前需要人工审核。**
