# Glencoe Math Course 1–3（McGraw Hill，六到八年级）

本目录整理 McGraw Hill **Glencoe Math** Course 1–3（六到八年级）的章节结构，并为每章做一张中文知识海报。教材**没有开放许可**（© McGraw Hill，版权所有）。官方公开的目录只到章一级（见 McGraw Hill 2022 学校产品目录），所以海报每行的知识点是按章名挑选的，不代表原书课次（待核）。

> **AI 辅助声明**：本目录的大纲和海报由 AI 辅助整理和绘制，中文是本项目的译写，没有照搬原文，也没有使用原教材的题目和插图。海报里的数字和情境标「示例」，属于自编示意；拿不准的地方标「待核」。**公开发布或用于教学前需要人工审核。**
