# 点亮工坊

给 6–16 岁孩子的科技兴趣工坊。孩子先让一盏灯亮起来，再弄懂磁和电怎样互相转化，然后做出能带回家的闹钟和小车。

每节课让一个现象发生，学期结束带走一件能向家人演示的作品。完整的课程、选址、装修和经营方案在 [设计稿](设计稿.md)。

## 四条课程线

| 班 | 年龄 | 带回家里的作品 |
| --- | --- | --- |
| 点亮班 | 6–8 岁 | 纸盒小夜灯、电磁起重机 |
| 磁电班 | 9–11 岁 | 手摇小灯或门磁报警器 |
| 闹钟班 | 12–14 岁 | 会响的台式闹钟 |
| 小车班 | 13–16 岁 | 沿黑线走或会避障的小车 |
