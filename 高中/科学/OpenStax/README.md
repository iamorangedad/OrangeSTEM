## 海报

教材篇幅很长，按约定每章一张海报，共 91 张，按学科放在 `海报/生物/`、`海报/化学/`、`海报/物理/`。已完成 0 张（PNG + PDF）：生物 0、化学 0、物理 0。每张海报 3 行，每行概括这一章的一节或几节（标出节号），配一张示意图；小结框有 4 条要点，其中有拓展和安全提示；底部标注教材来源和许可。海报只用公制单位和人民币；教材没有给出的数值不编造，为说明而举的数字标「示例」。化学海报不给配方，试剂用量和操作以教师指导和学校实验室安全规定为准。
