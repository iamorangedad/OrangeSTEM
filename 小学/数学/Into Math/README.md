# Into Math K–5

本目录的海报以 Houghton Mifflin Harcourt（HMH）出版的小学数学教材 **Into Math** K–5（Common Core 版）为蓝本。这是商业教材，课文只有登录 HMH Ed 才能看到，所以海报**只把教材的单元、模块和课题列表当作来源引用**，没有复制教材的文字、图片或习题。

- 海报里的例题和数字都是自己编的，标「示例」；画动手活动的地方注明「步骤为示意」。海报只用公制单位和人民币。
