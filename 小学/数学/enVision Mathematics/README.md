# enVision Mathematics K–5

本目录的海报以 Savvas Learning Company 出版的 **enVision Mathematics**（Common Core 版，© 2024）为蓝本。这是商业教材，课文只有登录 Savvas Realize 才能看到，所以海报**只把教材公开的主题和课题列表当作来源引用**，没有复制教材的文字、图片或习题。

- [各年级大纲与完整课次表（Markdown）](大纲.md) · [PDF](大纲.pdf)
- 来源与核对情况见大纲开头：主题和课题列表取自 IXL 公开的 enVision Mathematics (2024) 对齐文件；四年级 16 个主题已与 Savvas 官方介绍材料核对一致，其他年级**标为待核**。
- 海报里的例题和数字都是自己编的，标「示例」；画动手活动的地方注明「步骤为示意」。海报只用公制单位和人民币。
- 海报由 AI 辅助生成，公开使用前请由老师人工审核。
